# GettingStarted

Reveal SDK getting-started sample for Angular. Built with [Angular CLI](https://github.com/angular/angular-cli) 22.2.0 and `reveal-sdk` 2.2.1.

## Prerequisites

- Node.js `^22.22.3` or `^24.15.0` (required by Angular 22)
- A Reveal server running on `http://localhost:5111` (see the `server` samples)

## Development server

Run `npm install`, then `npm start` (or `ng serve`) for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## Build

Run `npm run build` (or `ng build`) to build the project. The build artifacts will be stored in the `dist/` directory.

## Further help

To get more help on the Angular CLI use `ng help` or go check out the [Angular CLI Overview and Command Reference](https://angular.dev/tools/cli) page.
