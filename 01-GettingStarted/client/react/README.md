# Getting Started with Reveal SDK and React

Reveal SDK getting-started sample for React 19, built with [Vite](https://vite.dev) and `reveal-sdk` 2.2.1.

## Prerequisites

- Node.js `^20.19.0` or `>=22.12.0` (required by Vite 8)
- A Reveal server running on `http://localhost:5111` (see the `server` samples)

## Available Scripts

In the project directory, run `npm install` first, then:

### `npm run dev` (or `npm start`)

Runs the app in development mode. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### `npm run build`

Type-checks the project and builds it for production to the `dist` folder.

### `npm run preview`

Serves the production build locally.
